# Lionic

Responsive landing page built as a frontend practice project.

The project is focused on semantic HTML structure, clean CSS styling, reusable layout patterns and responsive web design.

## Demo

[Live Demo](https://roman-werstka.github.io/Lionic/)

## About

Lionic is a multi-section landing page created as an educational frontend project.

The page includes:

- Header navigation
- Hero section
- Services section
- Articles section
- Client reviews
- Contact section
- Call-to-action blocks

## Technologies

- HTML5
- CSS3
- Flexbox
- BEM-style class naming
- Responsive Web Design
- Normalize.css

## Features

- Semantic HTML structure
- Multi-section layout
- Reusable CSS classes
- Flexbox-based layouts
- Styled buttons and navigation
- Responsive-ready structure
- SVG icons and optimized image assets

## Run Locally

Clone the repository:
```bash
git clone https://github.com/roman-werstka/Lionic.git
```

Then open `index.html` in your browser.
